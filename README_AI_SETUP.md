## 1. PC 로컬 HTML 테스트 방법 (필수: http://localhost:8080)
- **Windows:** `start_local_test.bat` 더블클릭 → 브라우저에서 `Ctrl + Shift + R` 강력 새로고침
- **macOS / Linux:** `python3 -m http.server 8080 --directory www` 실행 후 `http://localhost:8080` 접속

## 3. GitHub 업로드 및 OTA 배포 / APK 빌드 순서
1. `261126_kotonoha-app-v2.5.1.zip` 압축 해제 후 `kotonoha-app-main` 안쪽 파일 전체를 GitHub `main` 브랜치에 업로드(Push)합니다.
2. GitHub **`Actions`** 탭에서 `build-ota` → `deploy-ota` 및 `build-apk` 초록색 체크(✓) 완료를 확인합니다.
3. 완료 화면 하단 **`Artifacts`**에서 `kotonoha-android-apk-ota`를 내려받아 설치하거나, 기존 OTA APK 사용자는 앱 내 **⚙️ 설정 → 데이터 · 캐시 → 최신 버전 즉시 업데이트**를 누르면 `v2.5.1`이 즉시 적용됩니다.
