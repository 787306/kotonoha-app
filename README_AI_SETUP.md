## 1. PC 로컬 HTML 테스트 방법 (필수: http://localhost:8080)
- **Windows:** `start_local_test.bat` 더블클릭 → 브라우저에서 `Ctrl + Shift + R` 강력 새로고침

## 3. GitHub 업로드 및 OTA 배포 / APK 빌드 순서
1. `261126_kotonoha-app-v2.5.4.zip` 압축 해제 후 `kotonoha-app-main` 안쪽 파일 전체를 GitHub `main` 브랜치에 업로드(Push)합니다.
2. GitHub **`Actions`** 탭에서 `build-ota` → `deploy-ota` 및 `build-apk` 초록색 체크(✓) 완료를 확인합니다.
3. 완료 화면 하단 **`Artifacts`**에서 `kotonoha-android-apk-ota`를 내려받아 설치하거나, 기존 OTA APK 사용자는 앱 내 **⚙️ 설정 → 데이터 · 캐시 → 최신 버전 즉시 업데이트**를 누르면 `v2.5.4`이 즉시 적용됩니다.

## 4. v2.5.4 추가 패치 (자유 프리토킹 핸즈프리 실시간 통화형 UI)
- **`💬 자유 프리토킹 (주제 무제한)` 전용 통화형 하단 바:** 기본 화면에서 마이크·전송·입력칸·빠른 표현·힌트 버튼을 전부 제거하고 **`📞 실시간 대화 시작 / ⏹ 종료`** 대형 버튼 + **`🔇 음소거`** + 실시간 음량 레벨 미터만 표시합니다.
- **이중 엔진 자동 전환:**
  1. **Gemini Live 프로필 활성 시:** 버튼 한 번으로 양방향 실시간 음성 통화 즉시 시작 (말 끊고 끼어들기 가능).

- **조용한 곳용 숨김 토글:** 오른쪽 구석의 작은 **`⌨️ 키보드`** 버튼으로 필요할 때만 텍스트 입력창을 접었다 펼 수 있습니다. (`🎭 상황별 미션` 탭은 기존 학습용 입력창을 그대로 유지합니다.)

## 5. v2.5.4 추가 패치 (모바일 화면 최적화 · 홈 단순화 · 프리토킹 8인 파트너 및 자연 음성)

- **안드로이드 스마트폰 가로 너비 전면 최적화:** `html, body` 및 메인 Flex 래퍼(`min-w-0`), 잠금화면, 어휘 필터·카드, AI 프로필 카드 버튼 5종, 앱 설정 허브 배지 너비를 360px 좁은 폰 화면에 맞춰 넘침·잘림·세로 찌그러짐을 전부 해결했습니다.
- **프리토킹 8인 대화 상대 선택(여성 4명 · 남성 4명) & 자연 음성 개선:**

  - 저장된 Gemini Live 키가 있는데 턴제 모드에 머물러 있으면 하단에 **`⚡ 사람 목소리(Live)로 전환`** 원클릭 배너를 띄워 즉시 자연스러운 사람 목소리로 바꿀 수 있습니다.

## 6. v2.5.4 긴급 레이아웃 패치 (모바일 회화 파트너 헤더 글자 찌그러짐 해결)
- **원인 해결:** 4번 탭 파트너 정보 행의 `flex-wrap` + `flex-1 min-w-0` 조합이 모바일에서 `존댓말/반말` 버튼에 밀려 이름(`미.`)과 설명을 세로로 찌그러뜨리던 문제를 `flex-col sm:flex-row` 2단 적층 구조로 수정했습니다.
- **동일 패턴 일괄 보완:** 회화 상단 AI 엔진 바(`#ai-engine-bar`), AI 어휘 생성 입력창, 사전 검색 입력창, 통화 하단 바의 모바일 레이아웃을 함께 정리했습니다.

## 7. v2.5.4 추가 패치 (프리토킹 목소리 고정 · 말풍선 삭제/실행취소 · OTA 캐시 개선)
- **프리토킹 목소리 일관성 고정:**
  - 턴제 자유 프리토킹에서 내장 MP3와 여러 외부 TTS 서버가 섞여 턴마다 목소리가 달라지던 현상을 차단했습니다. 세션당 **단일 음성 엔진 고정** + 긴 문장 분할 재생 + 6.5초 타임아웃으로 일관된 목소리를 유지합니다.
  - Gemini Live 시스템 프롬프트에 선택한 파트너의 성별·연령·음색 일관성 유지 규칙을 보강했고, 예비 API 전환 시 목소리 변경 안내를 명확히 표시합니다.
- **프리토킹 대화풍선 삭제 기능:**
  - 각 말풍선(AI·사용자 모두)에 **개별 삭제** 버튼과 **5초간 `[실행 취소]` 토스트**를 추가했습니다.
  - 대화창 하단에 **`선택 삭제`** 모드를 추가해 여러 말풍선을 체크박스로 한 번에 삭제할 수 있으며, 턴제 AI 기억(문맥)에서도 즉시 제외됩니다.
- **OTA 업데이트 캐시 꼬임 해결:**
  - 모든 로컬 JS 불러오기에 `?v=2.5.4` 버전을 부여하고, `sw.js(v17)`에 `cache: 'no-cache'` 재검증 및 `최신 버전 즉시 업데이트` 시 서비스워커 초기화·강제 재로드를 적용했습니다.
  - `.github/workflows/main.yml`에서 저장소 최상단의 구버전 파일이 `www/` 최신 파일을 덮어쓰지 못하도록 안전 조건을 추가했습니다.
